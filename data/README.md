# Data

| Path | Tracked | Content |
| --- | --- | --- |
| `raw/` | no | tau-bench: `git clone --depth 1 https://github.com/sierra-research/tau-bench.git data/raw/tau-bench` |
| `probs/` | no | one JSON-lines file per labeler model, written by `nesymon.labeler.ProbCache` |
| `annotation_sheet_*.csv` | no | annotation sheets with conversation text, regenerated by `experiments/make_annotation_sheet.py` and `experiments/make_double_sheet.py` |
| `pilot_tasks.json` | yes | the 20 pilot tasks, excluded from every evaluation |
| `labels.csv` | yes | adjudicated pilot labels: `task_id, traj_id, step, prop, value, note` (linguistic propositions only) |
| `label_adjudication_history.csv`, `label_adjudication_notes.md` | yes | how the pilot disagreements were resolved |
| `labels_eval.csv` | yes | evaluation labels, 5,431 judgements on 145 tasks: agent pre-labels checked by a human reviewer (ground truth of all real-data results) |
| `labels_eval_annotator2.csv` | yes | independent second annotation of the same 5,431 judgements (kappa 0.936 with `labels_eval.csv`) |
| `double_annotation_tasks.json` | yes | the 29 tasks of the blind 20 percent double-annotation sample |
| `judge/` | yes | answers of the LLM-judge baseline, one JSON line per trajectory and rule |
| `preannotation/` | yes | instructions and raw outputs of the annotating agents, one folder per agent |
| `simon_full.csv`, `double_annotation_filled.csv` | no | the second annotator's sheets with conversation text (their labels are in `labels_eval_annotator2.csv`) |

The historical trajectories cover two agents (gpt-4o with 4 trials per task, sonnet-35-new with 8) on
retail (115 tasks) and airline (50 tasks): 1,980 trajectories with full tool-call logs. The evaluation uses trial 0
of both agents on every non-pilot task: 290 trajectories.
